TrixiCUDA.jl

TrixiCUDA.jl provides high-order DG solvers for hyperbolic PDEs with native CUDA.jl kernels.

Performance Benchmarks

Performance is tracked by benchmarking TrixiCUDA.rhs_hyperbolic!, the evaluation of the semidiscrete right-hand side, in Float64 on the initial mesh of each case. All cases are adapted from Trixi.jl or TrixiShallowWater.jl examples on TreeMesh. The cases are selected so that every right-hand-side code path in each spatial dimension is covered by two to three cases, or by the only available example where no second one exists.
